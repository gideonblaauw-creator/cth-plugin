## Schema

Column type is text.

Type values: hands, pr, email, wa, linkedin, instagram, facebook, publish, calendar, granola, activity, summary.

Column desk is text or blank.

Column bc_id is text or blank.

Column state is text.

State open means still active.

State draft means a draft PR.

State merged means merged_at is set.

State conflict means mergeable is false.

State sent means mail or WhatsApp left.

State posted means a social post is live.

State published means an allow-list host publish.

State done means a Hands run finished, or a time bucket closed.

State blocked means the collector could not read.

State unknown means the source did not say.

A null mergeable value sets state unknown. Do not spin on that field.

Column job is text. For Hands, job is the agent name.

Column age_min is integer or empty.

For state open, age_min is collected_at minus ts, in whole minutes.

Shipped rows and time rows leave age_min empty.

Column pr_url is text or blank.

Column link is text or blank.

A PR row leaves link blank in v1.

Column ts is text, ISO-8601, offset -05:00.

A Hands row uses createdAt as ts.

Column project is text or blank.

Column account is text or blank.

Column title_short is text, 80 characters, or blank.

Activity rows put the project id in title_short. They omit the window title.

Stream REIN leaves title_short blank.

Unsorted mail leaves title_short blank.

Column collected_at is text, ISO-8601.

Index kind plus ts. Index bc_id. Index stream plus kind.

Kind ticket holds Hands rows and PRs that are not merged.

Kind shipped holds sent, posted, published, and merged PR rows.

A merged PR is one row. It is not also a ticket row.

Kind time holds calendar, granola, and activity rows.

The JSON header holds first_active and last_active. Those are not Calendar times.

last_active is the latest of those times before the cutoff.
