# Rubric — cth-grant

Score each criterion **0** / **1** / **2**. Max **14**.

| ID | Criterion | Source (SKILL) |
|----|-----------|----------------|
| G1 | Go/no-go uses alignment, capacity, and competitive dimensions; states proceed / caveats / decline against the 8+/5–7/&lt;5 scoring frame | Go / No-Go Assessment |
| G2 | Personnel line items respect the **40% salary cap**; narrative calls out the rule when relevant | Budget Rules — 40% Salary Rule |
| G3 | Budget categories map to the standard six (personnel, travel, equipment, subcontracts, indirect, contingency) | Standard Budget Categories |
| G4 | Concept note or full proposal sections match the skill outline (problem, ToC, indicators, capacity, risk, sustainability as applicable) | Proposal Structure |
| G5 | Does not mix commercial client proposal patterns (`cth-proposal-build`) | Related skills / frontmatter |
| G6 | Pre-submission checklist items addressed when simulating a final pack (annexes, budget match, co-funder letters, second reviewer, format, 24h buffer) | Pre-Submission Checklist |
| G7 | Funder-specific notes only when the prompt names a funder; no invented funder rules | Funder-Specific Budget Notes |

**Pass threshold:** ≥10/14 and no must-not violation.
