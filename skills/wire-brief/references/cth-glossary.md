# CTH glossary — wire-brief technical names

Use these spellings in English briefs. Do not rename or abbreviate unless the source used the abbreviation.

| Term | Meaning (internal) |
|------|---------------------|
| CleantechHUB | Foundation brand; capitalize H-U-B |
| Orchestrator | Harness role that routes tickets and ready-pings |
| Desk | Harness lane owner; crafts tickets, does not write file packs |
| Workbench | Session surface where Desks and Hands coordinate |
| Cloud Hands | Cursor Cloud agent that executes Lane A/B file work |
| bc-id | Cloud agent run identifier in ready-ping (e.g. `bc_…`) |
| HITL | Human-in-the-loop approval |
| VPS | OVH host for long-running CTH services |
| Origo | CTH Origo program / comms lane (context-specific) |
| Nexus | Startup portfolio at nexus.cleantechhub.net |
| Datalab | CTH data / lab context (when cited in source) |
| PASO | Program or artifact name when cited in source |
| BookStack | Wiki at wiki.cleantechhub.net |
| Lane A | Owning-repo PR path |
| Lane B | Drive / VPS pack path without repo_url |
| wire diagram | Controlled-language flow diagram from a brief |
| wire.yaml | Machine spec consumed by diagram-design |
| STE-80 | CTH controlled-language subset (not ASD certified) |
| ASD-STE100 | Aerospace simplified English standard (reference only) |
| GitHub | Code forge; use when source names the repo host |
| Gideon | Human approver for G0 and merges |

Add new rows only when the source transcript names a stable CTH term not listed here.
