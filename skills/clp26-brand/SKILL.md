# ClimateLaunchpad 2026 Campaign Brand

Apply these rules to every piece of CLP26 campaign content. CleantechHUB is the National Organizer — never claim ownership of the ClimateLaunchpad brand itself.

## Program Context

ClimateLaunchpad (CLP) is the world's largest green business idea competition. CleantechHUB runs the Latin American campaign for CLP26 across five countries: Colombia, Peru, El Salvador, Guatemala, and Costa Rica. The campaign runs over a 6–8 week window.

## Visual Identity

### Color Palette

| Role | Name | Hex | Usage |
|------|------|-----|-------|
| Primary | CLP Green | #00A651 | Headlines, CTAs, key accents |
| Secondary | CLP Dark Green | #006838 | Text overlays, footer bars |
| Accent | CLP Yellow | #FFC425 | Highlights, badges, attention-grabbers |
| Background | CLP Light | #E8F5E9 | Section backgrounds |
| Text | CLP Black | #1A1A1A | Body copy |

These are the ClimateLaunchpad brand colors, distinct from CleantechHUB's palette. Use CLP colors for all CLP26 campaign content. Do not mix in CleantechHUB Deep Blue (#0C498A) as a primary element — it may appear only in the CleantechHUB attribution line.

### Typography

- **Headlines:** Montserrat Bold.
- **Body:** Open Sans Regular, 16px.
- **CTA text:** Montserrat SemiBold.

### Templates

Always use official ClimateLaunchpad Canva templates when available. If creating from scratch, match the CLP visual style — bold green backgrounds, yellow accent elements, clean sans-serif typography.

## Campaign Content Rules

### Language

- **Default language:** Spanish (Latin American neutral).
- **Pronoun form:** Use "tú" (not "usted") unless country-specific guidance from the user overrides this.
- **English:** Only for LinkedIn cross-posts explicitly targeting international audiences. When cross-posting, create a separate English version — do not mix languages in a single post.

### Hashtag Framework

Every CLP26 post must include this core set:

```
#ClimateLaunchpad #CLP2026 #CleantechHUB
```

Add topic hashtags (pick 2-3):
```
#NegociosVerdes #StartupClimática #InnovaciónVerde #EmprendimientoVerde #AcciónClimática
```

Add country hashtags when targeting a specific country:
```
#ColombiaSostenible #PerúVerde #ElSalvadorVerde #GuatemalaVerde #CostaRicaVerde
```

Total hashtags per post: 5–8 maximum. Never exceed 8.

### Post Structure (Spanish)

Follow this sequence for every social media post:

1. **Gancho** — A question, bold statement, or data point that stops the scroll.
2. **Cuerpo** — What CLP offers, the deadline, eligibility criteria, or a benefit.
3. **CTA** — A clear action: "Aplica ahora", "Regístrate aquí", with a link.
4. **Hashtags** — 5–8 per the framework above.

### Milestone Logic

Map all content to the current campaign phase:

| Phase | Weeks | Content Focus | Tone |
|-------|-------|---------------|------|
| Awareness | 1–2 | What is CLP? Program benefits, past winners | Informative, inspiring |
| Engagement | 3–4 | Success stories, mentor spotlights, FAQs | Social proof, credibility |
| Urgency | 5–6 | Deadline reminders, last-chance CTAs | Urgent, direct |
| Closing | 7–8 | Final push, step-by-step application instructions | Action-oriented, supportive |

When you do not know the current week, ask the user which phase the campaign is in before writing content.

### Supporter Attribution

When a post features a supporter organization:

- Always include their name and tag their social account.
- Include their logo in visual content when format allows.
- Never misattribute support — verify the organization name with the user if uncertain.
- Position supporter mentions after the main CLP content, before hashtags.

## Platform-Specific Rules

### LinkedIn

- Professional tone with data-driven hooks.
- Tag both the CleantechHUB and ClimateLaunchpad company pages.
- Image dimensions: landscape 1200x627px.
- Longer captions acceptable (up to 1300 characters).

### Instagram

- Visual-first. Prefer carousels for storytelling (3-5 slides).
- Image dimensions: square 1080x1080px or vertical 1080x1350px.
- Use Stories for deadline countdowns and behind-the-scenes content.
- Keep captions under 500 characters for feed posts.

### Facebook

- Community-oriented tone, share-friendly format.
- Use link posts when driving traffic to the application page.
- Image dimensions: 1200x630px.
- Captions can be conversational and slightly longer than Instagram.

## Quality Checklist

Before delivering any CLP26 content, verify:

1. Colors are from the CLP palette (not CleantechHUB palette).
2. Language is Latin American Spanish with "tú" form (unless overridden).
3. Hashtags include the three mandatory tags plus 2-5 contextual ones.
4. Content maps to the correct campaign phase.
5. CleantechHUB is attributed as National Organizer, not brand owner.
6. Supporter organizations are correctly named and tagged.
7. Image dimensions match the target platform.
8. CTA includes a clear action verb and link placeholder.
