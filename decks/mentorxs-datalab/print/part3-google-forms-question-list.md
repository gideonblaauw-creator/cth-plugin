## Bloque A — Tarjeta datos → valor (Q3)

### A1. Usuario

1. Rol / cargo de la persona que decide esta semana  
2. Tipo de organización (p. ej. clínica, fábrica)  
3. De qué es responsable esta semana  

### A2. Decisión

4. En una frase: ¿debería [acción] antes de [cuándo]? (decisión única)

### A3. Preguntas (2–3)

5. Pregunta 1 (sí/no o cuánto)  
6. Pregunta 2  
7. Pregunta 3 (opcional)  

### A4. Números (uno por pregunta)

Para cada N1, N2, N3 (opcional):

8–10. Métrica / unidad  
11–13. Responde a pregunta (Q1/Q2/Q3)  
14–16. ID de dataset (D1…)  
17–19. Rung medallion (None / Bronze / Silver / Gold)  
20–22. Mostrar como (firme / estimado)  
23–25. Panel sandbox (Baseline / Delta / Landscape)  

### A5. Valor

26. En una frase: ¿qué vale esta decisión? (dinero, riesgo, tiempo, salud)

### A6. Audiencia y límites

27. Quién puede ver esta pantalla  
28. Quién no debe verla  
29. ¿Tablero público? (No obligatorio si hay derechos abiertos)

### A7. Autocontrol (equipo)

30. Cada número tiene ID de dataset y tarjeta Q2  
31. Ningún número firme sin Silver+  
32. Cada número tiene panel sandbox  
33. Si hay derechos abiertos: tablero público = No  
34. Si combina paneles en mapa: re-chequeo G9
