# Cursor skill stubs

These folders exist so Cursor can discover CTH skills. Each `SKILL.md` is a pointer.

Canonical playbooks live in `skills/<name>/SKILL.md`. Read those files. Do not duplicate them here.

Authoring new skills: read `skills/skill-template/SKILL.md` first.

Presentations HTML+SVG diagrams (no Mermaid): canonical playbook `skills/diagram-design/SKILL.md`.

Intentionally omitted:

- `secrets` — do not load in Cursor
- `dual-desktop-macos` — Claude Desktop only; not on `main`
